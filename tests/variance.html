Variance Report

The authoring instrument for the segment model. The path table is exhaustive — every week the content can produce, run through the full balance suite, so a branch that breaks the envelope shows up here rather than in play. The draw table is sampled, because magnitude and incidence are continuous; it reports the worst draw, never the mean. The last column of the spread table is the one that matters most: it is the answer to “is this week actually different twice in a row?”
